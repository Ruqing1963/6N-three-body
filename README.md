# 6N-three-body
Part XXI (Volume II): the three-twin correlation on the 6N lattice does not factorize into pairwise terms — U(j1,j2)=R3/(R2R2R2)!=1 everywhere. Total annihilation (R3=0) obeys a tiling criterion, not a dimension count; three consecutive twins tile Z/5, recovering mod-5 admissibility.
